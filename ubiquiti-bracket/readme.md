# Ubiquiti Device Bracket
Attaches Ubiquiti 48mm devices to the grid.
- [Ubiquiti U6 Mesh Access Point](https://techspecs.ui.com/unifi/wifi/u6-mesh)
- [Ubiquiti G5 Flex 2k Camera](https://techspecs.ui.com/unifi/cameras-nvrs/uvc-g5-flex)
- [Ubiquiti G3 Flex 1080p Camera](https://techspecs.ui.com/unifi/cameras-nvrs/uvc-g3-flex)

The access point is our primary networking interface between wireless devices (traction controllers) and the backbone network.
The small device is fed with data and power using a single ethernet cable using PoE.
Up to 300 devices can be connected to the access point at once.

The camera is attached thru a single ethernet cable, which powers it over PoE.
A infrared-based night mode enables viewing the fiddle yard, even when the lights are off.
It can be accessed remotely, while recording locally to our router.
We use the camera to view our hidden sections during operation, and to reconstruct accidents on the layout.

Required non-printed parts:
- 1x [DIN 912 M5x16 screw](https://www.sfs.ch/de/Befestigungstechnik/Metrische-Schrauben-und-Zollschrauben/Zylinderschrauben/Zylinderschrauben-Innensechskant-mit-Sperrverzahnung-DIN-912-rostfrei-A2-M8x16mm/p/494752)
- 1x [M5 slot nut](https://www.motedis.com/de/Hammermutter-B-Typ-Nut-8-M5)
